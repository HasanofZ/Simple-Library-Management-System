# Library Management System (C# Console Application)
--------------------------------------------------------
A simple, well-structured console-based Library Management System built with  C#  and Object-Oriented Programming (OOP) principles. 

This project was developed as a hands-on practice to master fundamental programming concepts, data encapsulation, and object relationships.

##  Features
- **Book Management:** Add new books, track availability status, and view the book catalog.
- **Member Management:** Register new members and track their individual profiles.
- **Borrowing & Returning System:** Seamless workflow for members to borrow available books and return them back.
- **OOP Implementation:** Strictly follows encapsulation, associations (One-to-Many relationships), and separation of concerns across multiple classes (`Book`, `Member`, `Library`).

## 🛠️ Tech Stack
- Language: C#
- Paradigm: Object-Oriented Programming (OOP)
- Environment: .NET / Visual Studio

## 📂 Project Structure
- `Book.cs`: Manages book properties, validation, and Main Methods.
- `Member.cs`: Manages member details and lists of borrowed books.
- `Library.cs`: Acts as the central core managing collections of books and members.
- `Program.cs`: Provides the interactive CLI menu for user interaction.
